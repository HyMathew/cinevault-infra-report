# Provenance des dépendances de l'outil de sauvegarde

Ce répertoire contient notre orchestration Python, pas une implémentation cryptographique. Les programmes tiers sont téléchargés séparément ; leurs binaires, clés et archives de données ne font pas partie du dépôt.

[requirements.lock](requirements.lock) fixe les deux distributions Python et les SHA-256 des wheels publiées. [upstream.lock.json](upstream.lock.json) fixe les archives Windows x64 et Ubuntu 24.04 x64 et les binaires extraits. Les SHA-256 Mongo ont été comparés au [catalogue officiel full.json](https://fastdl.mongodb.org/tools/db/full.json) ; ceux d'age aux métadonnées de la release GitHub officielle, le 13 novembre 2026. Le verrou est une racine de confiance revue dans Git ; l'installateur ne remplace jamais ses valeurs par celles d'un téléchargement en cours. Il conserve les licences et, pour MongoDB Tools, les rapports SBOM et SARIF fournis dans l'archive. La preuve de transparence age n'est pas vérifiée par cet installateur.

100.20.0 est une base de qualification explicite, pas une affirmation de dernière version : la documentation Mongo annonce également 100.20.1. Une mise à jour exige revue des notes, renouvellement des hashes et requalification dump/restore ensemble. Le serveur accepté par cet outil est précisément 8.0.34. Le serveur MongoDB, son image, sa licence et son durcissement restent du ressort du déploiement ; cet installateur n'installe aucun serveur.

Le contrôle OSV du 13 novembre 2026 ne signalait rien pour les deux packages Python directs ni pour le module age 1.3.2. Le contrôle des modules Go du SBOM Mongo Windows et du manifeste embarqué age trouve néanmoins des avis de dépendances : [GO-2026-5932](https://pkg.go.dev/vuln/GO-2026-5932) vise OpenPGP ; [GO-2026-6354](https://pkg.go.dev/vuln/GO-2026-6354) et [GO-2026-6355](https://pkg.go.dev/vuln/GO-2026-6355) les connexions SSH ; [GO-2026-6860](https://pkg.go.dev/vuln/GO-2026-6860) et [GO-2026-6866](https://pkg.go.dev/vuln/GO-2026-6866) le traitement HTML. Notre invocation ne traite ni OpenPGP, ni connexions SSH, ni HTML ; les clés SSH et plugins age sont explicitement refusés.

Les binaires officiels age sont compilés avec Go 1.27.0, et Tools avec Go 1.27.3. L'interrogation OSV de leurs bibliothèques standard n'est pas vide : 15 avis pour 1.27.0, un pour 1.27.3. Ils concernent HTTP/HTTP2, templates HTML, MIME, TLS/X.509 et [os.Root.Mkdir(All) sous Windows](https://pkg.go.dev/vuln/GO-2026-6604) ; le dernier avis pour Tools est [GO-2026-6859](https://pkg.go.dev/vuln/GO-2026-6859), serveur HTTP MaxBytesReader. Les programmes sont invoqués localement pour des flux de fichiers, des clés natives et le protocole MongoDB, sans serveur HTTP, template/MIME, connexion TLS d'age ou création de répertoire via os.Root. La protection de chemins de notre wrapper est réalisée par Python et ses contrôles de liens/ACL. Cette analyse de surface ne constitue pas une preuve exhaustive de joignabilité de chaque symbole Go, ni une acceptation générale de ces bibliothèques dans d'autres usages. Refaire le contrôle amont et envisager une release officielle reconstruite avec un compilateur corrigé lorsqu'elle est disponible ; renouveler alors les verrous et essais. Conserver les notices amont lors d'une redistribution.
