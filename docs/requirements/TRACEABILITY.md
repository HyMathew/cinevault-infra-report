## Périmètre et lecture

- Statuts autorisés : `TODO` = non commencé ; `IN_PROGRESS` = partiel ou preuve insuffisante ; `IMPLEMENTED` = réalisé mais contrôle insuffisant ; `VERIFIED` = preuve effective de l'exigence telle que formulée ; `BLOCKED` = empêchement externe confirmé, à expliciter. `IMPORTANT` indique une exigence académique obligatoire ; toutes les lignes de ce tableau le sont.
- Une preuve historique reste identifiée comme telle ; elle n'est pas assimilée à une revalidation courante. Une réalisation locale vérifiée ne prouve pas un déploiement RemoteLabz. `VERIFIED` est limité au périmètre explicite de la ligne et peut devoir être revalidé après modification.
- Audit du code et des références le 6 novembre 2026 : web `4098834`, API `119c2b6`, arbres Git propres lors du contrôle ; infrastructure sans dépôt Git initialisé. **Revalidation fraîche** : pytest API Windows 20/20 et web Windows 9/9 réussis, avec désactivation du cache pytest ; ces chiffres ne prouvent pas à eux seuls l'intégration. Les 10 contrôles Compose au même couple de commits sont une **preuve antérieure**, enregistrée dans résultats (preuves locales non publiées) et contexte (preuves locales non publiées), pas une nouvelle exécution durant cet audit.
